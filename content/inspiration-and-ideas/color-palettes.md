# Color Palette Ideas

## The colors used in your project help set the tone and the mood you would like to be portrayed. For scrapbooking every page can have a different color palette and aesthetic. Check out our page on [[layout-themes]] for ideas. That is what makes them so fun and unique. You can alt for it to be synchronous too, but that isn't seen as much with scrapbooking.

> The colors that we choose are important because they evoke a feeling and help transform our work into a connection of the memory we are trying to remember with our pages.

### The most popular color styles include :
- Monochromatic- This style includes one base color with different shades.
- Analogous- This style uses three colors sitting next to each other on the color wheel. 
- Complementary- This style uses two colors that sit directly across each other on the color wheel to create a high contrast.
- Neutral- This style is chosen based on the undertones.
- Tetradic- This style uses four colors that pair into two.
- Triadic- This style uses three colors on the color wheel that spaced out evenly like a triangle.
